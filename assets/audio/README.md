# Horror Audio Files

Aggiungi i seguenti file MP3 in questa cartella:
- eyes_open.mp3 (creepy eye opening sound ~300ms)
- creature_approach.mp3 (low growl/creature approaching ~600ms)
- chaos_peak.mp3 (intense screech/noise ~400ms)
- white_flash.mp3 (bright noise burst ~400ms)

FONTI LIBERE:
- Freesound.org (search: horror, creature, screech)
- Itch.io (search: horror sfx)
- Zapsplat.com
- OpenGameArt.org

L'app funzionerà senza i file audio (graceful fallback), ma con i suoni sarà molto più impattante!
